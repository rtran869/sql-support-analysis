# SQL Support Data Analysis Project

This project demonstrates SQL-based troubleshooting and data validation in a customer support environment.

## Key Focus Areas
- Identifying data discrepancies between systems (POS vs reporting)
- Analyzing ticket volume, resolution time, and escalations
- Detecting recurring issues across locations

## Skills Demonstrated
- SQL (joins, aggregations, filtering)
- Data validation and reconciliation
- Troubleshooting support issues
- Root cause analysis
